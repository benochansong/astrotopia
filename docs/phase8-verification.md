# Phase 8 구현 및 검증 보고서

기반 커밋은 Phase 7 `9127742`이며 작업 브랜치는 `codex/phase-8-ancient-secrets`입니다. 기존 Phaser Canvas, TypeScript, Vite, 전투·직업·산업·행성별 저장을 확장했습니다. 새 서버나 외부 API 없이 로컬 싱글플레이로 동작합니다. 도메인·DNS·배포 설정은 변경하지 않았습니다.

## 구현

- 여섯 행성 보스 처치 및 분석 기록을 사용하는 OMEGA 해금. 코어 아이템은 소비하지 않으며 이미 제작에 쓴 경우도 지원합니다.
- GENESIS KEY 영구 플래그, 이전 행성 재료로 설치하는 항법·선체 차폐·중력 안정화 모듈. HORIZON과 탐험복 진입 조건, 왕복 항해·현지 비상 연료.
- 실제 이동 가능한 6개 OMEGA 지역과 3개 별도 던전. 포털, 자원 채굴, 회복소, 체크포인트, 지역별 적 배치.
- 0.1–1.8G 가변 중력, 지정 반중력 부유 구역, 고정 출구 공간 균열, 적·발사체 이동만 늦추는 국소 시간장.
- 고대 방사선, EP 간섭, 예고된 에너지 폭풍, 감시 드론. 탐험복·차폐 코어·부츠·위상 안정기·스캐너 5종.
- 에너지 연결·중력 정렬·상징 해독·보안 우회·기억 재구성 순서 퍼즐. 틀리면 진행만 초기화하고 도움말 제공, 부분 진행과 보상 저장.
- ECHO의 다섯 기억, AETERNUM과 일곱 세계의 역할, 30초 최초 착륙 장면, 각 15초 기억 재생.
- 신규 일반 적 8종: Ancient Watcher, Phase Stalker, Quantum Wraith, Gravity Sentinel, Nexus Hunter, Aeternum Golem, Archive Defender, Genesis Enforcer. 이동·순간 전이·보호막·광선·지면 파동·돌진·드론 호출의 차이.
- 에테르눔 수호자, 3단계 넥서스 오버로드, 5단계 GENESIS ZERO. 공급 장치, 보호막, 반격 창, 단계별 공격 정리, 군중 제어 저항, 안전 EP 충전, 사망 후 재도전.
- FREEDOM / HARMONY / REBIRTH 선택과 확인, 즉시 저장, 75초 엔딩, 건너뛰기·재생·장면 중 재접속. 다른 결말 재생은 저장된 선택 불변.
- 엔딩별 ECHO 대사·OMEGA 색상·제목 변화. 세 엔딩 모두 같은 자유 탐험·성장·도전 콘텐츠에 접근합니다.
- 방문 후 레벨 100, 초과 XP의 상한 있는 직업 숙련 전환, ASCENDED PIONEER 승격.
- 고대 소재 21종, 연구 5종, 기존 제작·강화와 연결한 7개 무기 변형 및 6직업×3부위 세트. 전설 제작, 확정 초월 승급, 강화 보존.
- 별도 2슬롯의 행성 유물 7개. 회복·중화기·EP·저항·산소·공중 전투 보조.
- OMEGA 독립 기지와 고대 시설 6종. 기존 작업 큐·전력·연료·창고·환경 차폐를 사용합니다.
- INFINITY NEXUS 10구간, 처치/장치/생존 목표, 5층 체크포인트. GALACTIC TRIAL 실제 보스 7연전과 회복 구간. 초월 TITAN / GENESIS 추가 패턴.
- 도전 원본 스냅샷 보존. 임시 자원·장비·피해는 본편으로 가져오지 않으며 완료 기록·정해진 보상만 반영합니다.
- 기록 임무 65–78, 일곱 행성 로컬 복원 납품, 다음 항성 신호.
- 도시 패럴랙스, 궤도 고리, 구역 표시, 적 실루엣, 기존 합성 음악의 OMEGA·보스 단계 변화.

## 저장 호환

버전 8. 버전 1–7 로드와 버전별 최초 백업을 유지합니다. 열쇠, 모듈, 방문, 퍼즐·부분 연결, 기억, 보스 기록, 임무 보상, 실제/대기 엔딩, 장면·재생 여부, 유물, 승격, 복원, 도전 체크포인트·결과를 검증합니다. 전설 이후 초월 장비도 유효한 저장으로 처리합니다.

기존 직업·SP·숙련·장비·강화·재료·행성 기지·우주선·연구·생산을 보존합니다. 신규 보스는 기존 직업의 보스 제어 저항 규칙에 포함됩니다. 비정상 값, 중복 유물, 잘못된 퍼즐 순서, 처치 없이 저장된 엔딩을 거부합니다.

## 확인한 문제와 조치

새 아이템이 늘어나 기존 기지 테스트의 모든 아이템 주입이 창고 용량을 넘었습니다. Phase 4 테스트는 해당 단계의 소재만 준비하도록 고쳐 실제 용량 검사를 유지했습니다. 7연전의 심해 준비 위치가 지형 보정으로 착륙점에 돌아가는 문제를 실제 보스 입장 좌표 설정으로 수정했습니다. 도전에서 죽은 임시 극한/ARES 적이 재생성되지 않도록 기존 적 AI의 `noLoot` 복제 개체 처리를 보완했습니다. 최초 착륙/엔딩 장면이 관리 창 뒤에서 멈추는 문제는 장면 시작 시 관리 창을 닫도록 수정했습니다.

모든 환경 모듈을 보유했을 때 기존 저장 검증 상한을 초과할 가능성을 실제 카탈로그 크기 기반 검증으로 수정했습니다. 중력 안정장의 효과가 다른 지역의 같은 좌표에 적용되지 않도록 기지 지역 여부를 확인합니다.

## 제한과 미구현

- 전체 1–100 신규 캐릭터 수동 완주, 여섯 직업의 최종 보스 6–10분 균형, 장시간 인간 플레이는 검증하지 않았습니다.
- 던전은 고정된 횡스크롤 지형이며 절차적 미궁 생성은 없습니다. 퍼즐은 단서 기반 순서 장치입니다. 완전한 천장 역중력 대신 지정 부유 구역을 사용합니다.
- 신규 무기는 기존 여섯 무기 행동의 변형입니다. 전용 애니메이션 전체 세트, 독립 드론 지휘 무기 엔진과 각 직업 세트별 새로운 액티브는 없습니다. 3부위 효과는 공통 상한 보너스입니다.
- 승격은 EP 재생 보너스이며 네 번째 직업이나 독립 궁극기 강화 트리는 없습니다.
- 기억과 엔딩은 성계 기록 중심의 절차적 연출입니다. 실제 기지 전체를 촬영한 몽타주, 성우, 녹음된 전용 사운드트랙은 없습니다.
- 환경 복원은 각 행성 기지의 자원 납품 기록입니다. 전체 지형 변경·외교·온라인 경제·다른 항성계 맵은 없습니다.
- 신규 자료는 ECHO 기록 UI 중심입니다. 기존 모든 도감 화면의 디자인을 새로 만들지 않았습니다.

## Phase 9 연결 지점

실제 엔딩 선택, 일곱 행성의 독립 창고·기지, HORIZON 화물, 글로벌 연구, 레벨·직업 상한, 복원 기록을 후속 문명 시스템이 사용할 수 있습니다. 기본 물류·경제는 엔딩 전에도 연구·시설을 충족하면 사용하고, 엔딩 전용 콘텐츠는 실제 완료 플래그로 제한하도록 이어갈 예정입니다.
