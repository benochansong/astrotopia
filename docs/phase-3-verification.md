# Phase 3 검증 기록

2026-11-26 / Windows / Chrome / TypeScript + Vite + Phaser Canvas.

## 자동 로직 검증

npm test: 67개 통과. 기존 이동·점프·채굴·전투·타이탄 회귀와 다음 항목을 포함합니다.

- v1/v2→v3 이관, 기존 장비·퀘스트·자원 보존, 잘못된 저장 구조·조작된 생산 비용·중복 작업 ID 거부.
- 안전 대기의 산소 유지, 동굴 진입 유예·산소 감소, 마스크·차폐복 저항, 안전 지대 노출 회복, 산소통·재사용 대기.
- 도구 등급 제한, 이동 중 채굴 취소, 성공 시 에너지 비용, 광물 재생 대기 저장.
- 가방+창고 원자적 재료 차감, 배치 생산, 단 한 번의 완성품 회수, 공간 부족 시 결과물 보관, 취소 재료·포인트 반환.
- 생산 대기열 저장·오프라인 복원, 역행·과도한 시계 변화 방어, 연구 선행 조건·비용·중복 방지.
- 환경 장비 6개 제작과 슬롯 교체, 무기 18개 레시피, 강화 +5 상한 및 저장, 창고 용량·수량 이동.
- 지정 비콘 위치, 보스 중 긴급 귀환 제한, 위험 저장 안전 복귀, 파수꾼 공급 장치·보호막·첫 보상.
- 퀘스트 11–18 생산 진행 통합: 실제 광물 노드와 레시피로 필요한 재료를 마련하고 시설 수리 → 연구 → 장비 제작 → 보스 보상 → 최종 설계도까지 완료합니다.

## 브라우저 검증

개발 Chrome 시나리오 6개를 실행했습니다. 기존 3개, Phase 2 전투 1개, Phase 3 제작·창고 1개와 연구·환경·파수꾼 1개입니다. 메뉴 저장 알림이 숨겨지는 회귀를 발견해 메뉴 하단 알림으로 수정했고 해당 시나리오는 재실행 통과했습니다. 여러 지역을 순회하는 신규 시나리오는 대기 시간을 포함하므로 90초 제한을 사용합니다.

실제 키 입력·버튼 클릭으로 생존 터미널 조사, 시작 재료 지급, 의료 젤 제작 대기·회수, 창고 수량 출고, 스캐너, 새로고침 후 보존, 연구 비용·완료·회수, 4개 지역 HUD와 조명, 파수꾼 공급 장치 화면을 검사합니다. 브라우저 오류 수집을 포함합니다.

## 범위와 한계

통합 캠페인은 기존 Phase 2 완료 상태에서 시작하며 이동 위치·전투 완료·광물 재생 대기를 단축합니다. 재료를 임의 지급하지 않고 실제 채굴 노드와 제작 레시피를 사용합니다. 사람 손으로 새로운 게임부터 전투·이동을 모두 완주한 기록은 아닙니다. 일반 난이도 장시간 밸런스, 다양한 PC의 60FPS, Firefox/Safari, 실제 스피커 청취는 검증하지 않았습니다.

저장 재생 방지는 현재 로컬 저장 안에서 완료 작업 재수령을 막는 방식이며, 사용자가 저장 파일 전체를 이전 버전으로 되돌리는 행위까지 방지하지는 못합니다. 대규모 건설·전력망·NPC는 Phase 4 범위입니다.

## 최종 배포 확인

npm run build 성공. 프로덕션 Chrome 테스트 1개 통과: 전체 오프닝, 키보드 이동·점프·조사, 메뉴·저장, 배포 번들의 개발 훅 제거를 확인했습니다. 개발 브라우저 6개 시나리오도 수정 대상 재실행을 포함해 모두 통과했습니다. 신규 지역·연구·파수꾼 시나리오 최종 실행은 46.4초였습니다.

시작 지역의 실제 Canvas 출력 5초 샘플: 평균 89.45 FPS, 프레임 간격 p95 19.3ms. Windows 로컬 Chrome, 1440×900, 고효과, 최대 120FPS 설정입니다. 신규 지역·보스·장시간 세션 전체의 안정적 60FPS를 보증하는 측정은 아닙니다. artifacts/performance.json에 원본을 기록했습니다.
