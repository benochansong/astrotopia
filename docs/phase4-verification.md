## 자동 검증 범위

기존 이동·점프·단방향 발판·채굴·인벤토리·저장, 6무기·스킬·장비·훈련·타이탄, 환경·산소·파수꾼, Phase 3 생산·연구·임무 통합을 유지했습니다.

신규 테스트는 다음 동작을 검증합니다.

- v3→v4 이관, 무료 기존 시설 등록, 첫 건설 자재 한 번 지급, 기존 아이템·임무 유지, 이전 저장 백업.
- 배치 격자·겹침·필수 시설·자원 보호·지지 조건, 건설 비용 단일 차감, 건설 중 전액 반환, 완료 후 80% 반환, 중복 철거 방지.
- 발판 위 건설과 지지 발판 철거 제한, 창고 철거 시 초과 자원 보호, 저장 용량 증가, 기존 창고 업그레이드.
- 저장 ID·좌표·배터리·재료 비용 검증, 조작된 건설 환불 금액 거부, 부품의 한 번 납품, 코어 안정기 1개 생산 제한.
- 독립 전력망·중계기 정지/복구, 생존 우선 공급, 낮·밤 태양광, EU·s 배터리 충·방전, 실제 발전량 및 시설 작업 속도 업그레이드.
- 매장지·전력·창고 연결 필수 조건, 실제 광물 자동 채굴, 최소 보유량, 입력 보관, 전력 중단 시 진행 유지와 재개.

스크린샷을 직접 열어 건설 패널·범위 표시·관제 센터·전력·인원·침공·전체 보기의 배치를 확인했습니다. 산출물은 `artifacts/phase-4-*.png`입니다.

## 수정한 문제와 한계

독립 망 사이에서 소비 시설이 잘못 중계 역할을 하지 않도록 제한하고, 겹친 공급 범위에서는 가장 가까운 망을 선택하도록 정리했습니다. v3 백업 이름, 저장 후 확장 지형의 안전 좌표 복원, 포탑 대기 시간의 음수 저장, 기존 창고 강화 용량, 건설 중 관리 메뉴 진입, 수동 작업의 전력/오프라인 일관성도 보완했습니다.

컨베이어·분배기·물류 드론·물류 로봇·외부 전초기지·독립 지하 건설·자동문·사다리·여러 유형 침공·행성 이동은 미구현입니다. 해당 선택 기능의 검사를 통과로 집계하지 않습니다. 중앙 창고 방식의 물류, 초기 기지 안의 매장지, 지상 침공과 강화 갑충을 구현했습니다.

정착민은 단순한 시설 배치 보너스 모델이며 로봇은 지상 장애물을 넘는 호버 이동 모델입니다. 복잡한 실내 경로·사회·식량 경제는 없습니다. 과도한 부하의 장시간 밸런스, 실제 스피커 청취, Firefox/Safari·터치·게임패드는 미검증입니다. 로컬 저장 전체 롤백·시각 위조를 막는 서버 권한은 없습니다.
