# ASTROTOPIA — Phase 8 · ANCIENT SECRETS

Phaser 3 / TypeScript / Vite 기반 2D 우주 탐험 RPG입니다. 기존 여섯 행성과 직업·산업·장비 시스템을 확장하여 일곱 번째 행성 OMEGA, 고대 문명의 기억, GENESIS ZERO와 세 가지 엔딩을 구현했습니다.

## 실행

```powershell
npm install
npm run dev
npm test
npm run build
npm run test:e2e
npm run test:production
```

개발 주소는 `http://127.0.0.1:5180`입니다. 프로덕션 검증은 먼저 빌드하세요. 상대 URL을 사용하며 외부 도메인이나 DNS 변경이 필요하지 않습니다.

이전 안내: [직업·전직](docs/phase7-guide.md), [극한 행성](docs/phase6-guide.md), [우주선](docs/phase5-guide.md), [기지 건설](docs/phase4-guide.md).

## OMEGA 진입

1. EDEN 타이탄 처치와 코어 분석, ARES 거신 처치와 산업 기록, 네 극한 행성 보스 처치와 기록 보관소를 완료합니다. LUNARIS에서 GENESIS 상징 분석까지 확보합니다. 코어를 제작에 이미 사용했어도 **처치·분석 기록**이 남아 있으면 됩니다.
2. L 연구에서 양자 공학 이후 **고대 기술 · 진입 차폐**를 연구합니다. 이전 행성의 공간 차폐 소재와 고대 연구 데이터가 필요합니다.
3. U → **ECHO · 고대 기록 → 여정**에서 GENESIS KEY를 제작합니다. 항법 수정 2, 양자 회로 2, 양자 에너지 셀 2가 필요합니다. 열쇠는 판매·소비되지 않는 영구 기록입니다.
4. 같은 메뉴에서 고대 항법 모듈, 양자 선체 보호막, 중력 안정화 엔진을 설치합니다. 모두 이전 행성에서 확보할 수 있는 소재를 사용합니다. HORIZON 선체와 세 모듈이면 진입할 수 있습니다.
5. L에서 **고대 탐험복**을 제작·장착하고 우주선에 탑승합니다. U → 항성계 지도 → OMEGA 항해를 선택합니다. 기본 편도 연료는 50이며 기존 추진·항법 보너스가 적용됩니다.

첫 착륙에는 30초 장면이 재생됩니다. F 또는 화면 버튼으로 건너뛸 수 있습니다. 현지 고대 합금 원석과 오메가 수정으로 비상 연료를 제작할 수 있어 돌아갈 길을 잃지 않습니다. OMEGA 방문 후 최대 레벨이 100으로 확장됩니다.

## 탐험 지역과 환경

| 지역               | 주요 진행                                                |
| ------------------ | -------------------------------------------------------- |
| 잊힌 착륙 항구     | 우주선, 회복소, 독립 기지 건설                           |
| 침묵의 대도시      | 에테르눔 수호자, 붕괴된 기록 보관소 입구                 |
| 중력 균열 지대     | 0.1–1.8G 구역, 부유 역장, 고정 출구 공간 균열, 중력 미궁 |
| 영원의 기록 보관소 | ECHO와 상징 기록, 국소 시간장                            |
| 연결의 요새        | 넥서스 금고, 넥서스 오버로드                             |
| GENESIS CORE       | 최종 보스와 문명의 선택                                  |

세 던전은 별도 지역인 **붕괴된 기록 보관소 / 중력 미궁 / 넥서스 금고**입니다. 각 지역의 왼쪽 포털로 착륙 항구에 돌아갈 수 있습니다. 회복소와 지역 진입 지점이 체크포인트로 작동합니다. 보스 재접속은 안전한 준비 지점에서 다시 시작합니다.

OMEGA의 고대 방사선은 탐험복·차폐 장비로 줄입니다. 양자 간섭은 EP를 서서히 소모하며 양자 차폐 코어 또는 위상 안정기로 막습니다. 폭풍은 2.5초 예고 후 지정 범위에 피해를 줍니다. 중력 제어 부츠는 고중력 부담을 줄이고 GENESIS 스캐너는 탐지 반경을 1,400으로 늘립니다. 착륙장과 각 지역 시작부는 안전 구역입니다.

중력 균열과 미궁의 x 3000–4000 역장에서는 Space를 유지해 부유합니다. 천장 충돌을 뒤집는 완전 역중력 대신 제한된 반중력 구역을 사용합니다. 기록 보관소 x 1800–3000의 시간장은 **적과 발사체 이동에만 0.55배**를 적용하며 생산·스킬 재사용·저장 시간은 바꾸지 않습니다.

## 고대 장치와 ECHO

현장 장치 근처에서 F를 누르면 퍼즐이 열립니다. 에너지 연결, 중력 정렬, 상징 해독, 보안 우회, 기억 재구성의 다섯 순서 퍼즐이 있으며 설명을 읽고 버튼을 순서대로 선택합니다. ECHO 도움말로 연결 순서를 확인할 수 있습니다. 오답은 연결만 초기화하며 자원·HP를 잃지 않습니다. 진행과 완료 보상은 저장되고 중복 수령되지 않습니다.

- 에너지 연결: 붕괴된 기록 보관소
- 중력 정렬: 중력 균열 지대
- 상징 해독: 영원의 기록 보관소
- 보안 우회: 중력 미궁
- 기억 재구성: 넥서스 금고

ECHO는 AETERNUM의 황금기, GENESIS 프로젝트, 경고, 침묵, 마지막 선택을 증언합니다. 다섯 기억은 각각 15초 재생되며 건너뛰기와 다시보기를 지원합니다. 일곱 세계의 역할은 생명·산업·초전도·에너지·적응·항법·중앙 판단으로 이어집니다.

65–78번 기록 임무는 ECHO → 여정에서 독립적으로 확인하고 보상을 받습니다. 기존 메인·직업 임무 기록을 덮어쓰지 않습니다.

## 보스 전투

**에테르눔 수호자**는 대도시에서 네 팔의 지면 공격과 보호막을 사용합니다. 보호막을 직접 공격하거나 x 3650 공급 장치에서 F로 해제할 수 있습니다. 수호자를 처치하면 연결의 요새가 열립니다.

**넥서스 오버로드**는 다섯 장치를 복구한 후 도전합니다. 체력 65%와 30%에서 방어 광선 → 공간 균열·드론·이동 발판 → 과부하·흡인·취약 코어로 전환됩니다.

**GENESIS ZERO**는 다음 다섯 단계로 전투합니다.

| 체력 구간 | 전투                               |
| --------- | ---------------------------------- |
| 100–80%   | 다중 광선 기동                     |
| 80–60%    | 이전 세계의 독성·열·냉기·전기 재현 |
| 60–40%    | 중력 변화와 코어 위치 전환         |
| 40–15%    | 방어막, 드론, 다중 방어망          |
| 15–0%     | 예고된 최종 NOVA 후 코어 반격 창   |

장비를 전투 중 바꿀 필요는 없습니다. 표시된 범위를 피하고 코어가 노출되면 반격하세요. x 3400–3650 안전 발판은 EP를 회복합니다. F 공급 차단은 18초마다 보호막 해제와 EP 회복을 제공합니다. 단계 전환은 공격과 소환을 정리하고 HP 10%·EP 30을 회복합니다. 보스는 강제 이동·군중 제어에 저항합니다. 사망 시 체크포인트에서 다시 도전하며 스토리 보상을 잃지 않습니다.

기본 체력은 420,000입니다. 목표 공략 시간 6–10분은 다양한 직업·장비의 장시간 수동 균형 검증이 더 필요하며 현재 측정 완료 수치로 주장하지 않습니다.

## 세 가지 엔딩

GENESIS ZERO를 정지시키면 다음 중 하나를 고르고 **선택 확정**을 누릅니다.

- 자유: 통제를 분산하고 기록을 보존합니다.
- 조화: GENESIS를 인간의 감독을 받는 제한된 조력자로 남깁니다.
- 재탄생: 중앙 통제를 해체하고 분산 복원망을 만듭니다.

세 선택 모두 같은 일곱 행성 자유 탐험과 성장·도전 콘텐츠를 이용할 수 있습니다. 실제 선택, ECHO 대사와 OMEGA 배경색이 달라집니다. 75초 엔딩은 건너뛰거나 기록 보관소에서 다시 볼 수 있습니다. 다른 결말 다시보기는 실제 저장된 선택을 바꾸지 않습니다. 장면 도중 재접속해도 이어집니다.

## 레벨 100, 장비와 유물

탐험·퍼즐·보스·기록 임무가 후반 경험치를 제공합니다. Lv.100 이후 XP는 현재 직업의 숙련으로 전환되며 기존 상한을 유지합니다. 엔딩 후 ECHO → 성장·유물에서 ASCENDED PIONEER로 승격하면 EP 재생 +1을 얻습니다.

고대 연구를 진행하면 기존 제작·강화·장착으로 7종 무기를 사용할 수 있습니다: GENESIS BLASTER, ETERNITY BLADE, OMEGA CANNON, QUANTUM DESTROYER, AETERNUM STAFF, NEXUS COMMANDER, VOID HAMMER. 기존 여섯 무기 판정을 확장한 변형이며 관통·콤보·차지·중력·순환 속성 등을 사용합니다.

각 직업에는 몸통·코어·부츠 3부위 세트가 있습니다. 현재 직업의 세 부위를 장착하면 공격 +6%, EP 재생 +1입니다. 제작은 전설 등급이며 엔딩 후 초월 합금 3·제네시스 파편 1로 초월 승급합니다. 기존 +0~10 확정 강화는 보존됩니다.

7개 행성 유물은 별도 슬롯에 최대 2개 장착합니다. HP 회복, 중화기, EP, 원소 저항, 산소, 공중 공격을 보조하며 직업·전투 장비·환경 모듈과 함께 사용합니다. 최초 복원에는 에테르눔 합금 2·기억 데이터 1과 해당 세계 기록이 필요합니다.

## 기지와 엔딩 이후

OMEGA 기지는 기존 B 건설·전력망·자동화·창고를 재사용하며 다른 행성과 독립적으로 저장됩니다. 고대 연구 센터, 양자 반응로, 유물 제작소, 중력 안정장, 에테르눔 기록고, GENESIS 네트워크 단말을 건설할 수 있습니다. 연구/제작은 실제 작업 큐에 연결되고, 반응로는 양자 안정 셀을 소비하며, 기록고는 창고를 240 늘립니다. 중력 안정장은 전력이 연결되면 주변 320 범위를 차폐합니다.

ECHO → 문명 복원에서 다음 콘텐츠를 시작합니다. 도전은 안전 기지에서 시작하며 본편 상태를 보존합니다. **기록 저장 · 본편 귀환**으로 종료하세요. 재접속해도 본편 상태가 유지됩니다.

- INFINITY NEXUS: 실제 10개 구간. 기존 행성 환경에서 처치·장치·30초 생존 목표가 순환합니다. 5층 완료 체크포인트와 최고 층수를 저장합니다.
- GALACTIC TRIAL: 실제 처치한 TITAN → COLOSSUS → LEVIATHAN → HELIOS → EMPEROR → ARCHON → GENESIS ZERO의 7연전. 구간마다 회복 후 다음 구간을 선택합니다.
- 초월 TITAN / GENESIS ZERO: 지연 교차 추적 공격을 추가합니다. TITAN은 별도 도전, GENESIS는 코어 현장에서 시작합니다.
- 완료 기록: 총 시간, 구간별 시간, 받은 피해, 사망, 직업, 무기 희귀도와 최고 기록을 로컬 저장합니다.
- 일곱 행성 복원: 문명 복원 연구 후 각 행성 기지에서 문명 복원 코어 1·철 주괴 5를 전달합니다. 일곱 복원망 연결 후 다음 여정의 신호가 열립니다.

## 저장과 구현 범위

저장 버전은 **8**이며 버전 1–7을 변환합니다. 기존 재료·레벨·장비·직업·우주선·행성 기지·생산·연구를 유지하고 이전 버전은 최초 저장 때 백업합니다. 열쇠·모듈·장치·기억·보스·엔딩·유물·초월·도전 기록을 추가 검증합니다.

절차적 Canvas 도시·도형 기반 적·음악 합성을 사용합니다. 퍼즐은 텍스트 단서를 가진 순서 장치이며 복잡한 배선 물리 시뮬레이터는 아닙니다. 던전은 고정 지형, 기억·엔딩은 절차적 성계 기록 연출입니다. 직업 세트 효과는 공통 능력치 보너스이며 독립 궁극기 업그레이드, 전용 무기별 새 애니메이션, 컷신 음성·고유 음악 녹음, 전 행성 지형 변환은 구현하지 않았습니다. 행성 복원은 로컬 기지 자원 전달 기록입니다.

자세한 구현·검증·제한사항은 [검증 보고서](docs/verification.md)를 참고하세요. Phase 9의 문명 발전은 엔딩 선택·행성별 기지·복원 기록을 이어받을 수 있도록 구성했습니다.
