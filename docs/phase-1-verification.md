# Phase 1 검증 기록

검증 날짜: 2026-11-26 (Asia/Seoul). 환경: Windows, Node.js 24.14.0, 로컬 Google Chrome, 1440×900 브라우저 창.

게임 흐름은 **타이틀 → 오프닝 → 로컬 게임 상태 → Canvas/DOM 표시 → LocalStorage 저장 → 새로고침 → 이어하기**입니다. 서버 API나 외부 데이터베이스를 사용하는 게임이 아니므로 API/DB 경계는 해당하지 않습니다.

## 자동 검사

| 검사                      | 결과              | 근거                                            |
| ------------------------- | ----------------- | ----------------------------------------------- |
| `npm run build`           | 통과              | TypeScript strict 검사, Vite 프로덕션 번들 생성 |
| `npm test`                | 40개 통과         | 아래 게임 로직 및 경로 검사                     |
| `npm run test:e2e`        | 3개 시나리오 통과 | 실제 Chrome에서 UI·키 입력·저장·복구 확인       |
| `npm run test:production` | 통과              | 개발 훅 없는 프로덕션 번들의 실제 실행 검사     |

### 게임 로직 40개

- 30/60/120Hz에서 이동 거리 오차 1px 미만, 바닥 침투 없음.
- 누르는 시간에 따른 점프 높이, coyote time, 착지 전 점프 버퍼.
- 단방향 발판 통과, 고체 바닥 통과 방지, 대시 중 벽 충돌.
- 대시 에너지 및 재사용 대기시간.
- 3개 지역의 필수 발판 연결 12곳을 실제 이동 함수로 점프. 숨겨진 보급품 접근과 두 협곡의 연결 포함.
- 채굴 완료·취소·재생성, 인벤토리 중첩·포화 처리.
- 투사체 명중·처치·경험치·드롭, 크롤러·만타의 예고 상태.
- 피격 무적, 사망 후 귀환과 경험치·아이템 유지.
- 4개 임무 조건 연결, 엔딩 이벤트, 엔딩 이후 이동.
- 양방향 지역 이동 및 최초 발견 보상 중복 방지.
- 레벨업 체력 회복, 최대 레벨 15.
- 저장 왕복, 공중 안전 위치, 잘못된 버전·JSON·자료형·아이템 ID 거부.
- 저장 권한/용량 오류, 위험 위치 보정, 사망 중 종료 후 체크포인트 복귀.

### 개발 빌드 Chrome 통합 시나리오

1. 타이틀과 저장 없는 이어하기 비활성 → 새 게임 → 오프닝 건너뛰기 → 실제 A/D·Space 입력 → F 조사·채굴 → 인벤토리 설명 → 지도 → 일시정지 → 수동 저장 → 새로고침 후 동일 아이템 확인 → 900×600에서 비율 유지.
2. 실제 J키로 적 처치 → 발광 숲·수정 계곡 렌더링 → 사망 화면과 부활 → 임무 완료 이벤트를 받아 엔딩 표시 → 자유 탐험 복귀.
3. 키보드 Tab/Enter 메뉴 접근 → 설정 저장 → 일시정지 시 게임 시간 불변 → 타이틀 복귀와 기존 기록 초기화 확인 → 손상된 저장 데이터 안내 및 이어하기 비활성.

**테스트 범위 구분:** 개발 빌드 E2E는 긴 이동 시간을 줄이기 위해 개발 전용 훅으로 일부 플레이어 위치와 임무 조건을 준비합니다. 조사·채굴·발사·메뉴·저장은 실제 브라우저 입력으로 검증합니다. 4개 퀘스트를 처음부터 끝까지 실제 키보드만으로 연속 완주한 수동 테스트로 간주하지 않습니다. 발판의 연결 가능성은 독립된 물리 테스트로 확인했습니다. 개발 훅은 프로덕션 빌드에서 제거됩니다.

## 프로덕션 실행과 성능 샘플

완성된 `dist/`를 Vite preview로 제공하고, 실제 Chrome에서 **24초 오프닝 전체를 건너뛰지 않고** 재생했습니다. 이어서 키보드 이동·점프·우주선 조사·일시정지·수동 저장을 확인했습니다. 개발용 `__ASTRO__` 훅이 없는 것도 확인했습니다. 이 검사에서 페이지 예외, 콘솔 오류, 요청 실패는 0건입니다.

최종 설정은 목표 60FPS, 최대 120FPS입니다. 높은 효과 설정, 1440×900 창에서 실제 Phaser 출력 Canvas의 `drawImage` 호출 간격을 5초간 측정했습니다. 이 게임은 출력 Canvas에 프레임당 게임 이미지를 한 번 그립니다.

- 평균 출력 호출률: **96.43 FPS**
- 프레임 간격 95백분위: **13.10ms**
- 원시 결과: `artifacts/performance.json`
- 최종 빌드 화면: `artifacts/production.png`

이 결과는 해당 기기의 불시착 지점에서 측정한 짧은 CPU 측 Canvas 출력 샘플입니다. 모든 지역·전투 부하·GPU 합성·물리 디스플레이 표시나 다양한 PC에서의 60FPS를 보장하는 측정은 아닙니다.

## 미검증 및 제한

- Firefox, Safari, 모바일, 게임패드 및 다양한 GPU/저사양 기기는 미검증입니다.
- 장시간 메모리 안정성, 수십 분 이상의 자유 플레이, 모든 위치에서의 모든 충돌 조합은 미검증입니다.
- 효과음 호출 및 오디오 설정 경로는 구현·검사했지만 자동화 도구로 실제 출력 소리를 청취한 것은 아닙니다.
- 전체 화면 버튼은 구현했으며, 사용자 환경별 전체 화면 정책과 실제 다중 모니터 동작은 미검증입니다.
- 공개 웹 배포, DNS·도메인·인증서 설정은 수행하지 않았습니다.
- 적과 드롭은 지역 이동 때 초기화됩니다. 채굴 재생성 타이머는 저장 데이터에 포함하지 않습니다.

발견한 기능 오류는 수정 후 관련 검사를 다시 실행했습니다. 위 자동 검사 범위에서 남은 실패는 없습니다.
