# ASTROTOPIA
## DEVELOPMENT PHASE 5 — BEYOND EDEN
### ONE PLANET WAS ONLY THE BEGINNING
### 하나의 행성은 시작에 불과했다

---

## 1. 프로젝트 개요

ASTROTOPIA는 2D 횡스크롤 액션 RPG에 우주 탐험, 생존, 자원 채굴, 장비 제작, 기지 건설, 산업 자동화 및 행성 개척을 결합한 독창적인 SF 게임이다.

이전 개발 단계의 목표는 다음과 같다.

### Phase 1 — THE FIRST LANDING

- 횡스크롤 게임 엔진
- 첫 번째 행성 EDEN
- 캐릭터 이동
- 기초 전투
- 자원 채굴
- 인벤토리
- 퀘스트 및 저장

### Phase 2 — BATTLE EVOLUTION

- 무기 6종
- 공통 스킬
- 전투 타격감
- 다양한 몬스터
- 엘리트 몬스터
- 장비 시스템
- EDEN TITAN 보스

### Phase 3 — SURVIVAL PROTOCOL

- 환경 위험
- 생존 장비
- 채굴 도구
- 자원 정제
- 장비 제작 및 강화
- 기술 연구
- 특수 탐험 지역
- ABYSS SENTINEL

### Phase 4 — COLONY RISING

- 자유로운 기지 건설
- 발전 및 전력 네트워크
- 자동 채굴
- 자동 정제 및 생산
- 물류 시스템
- 정착민 및 지원 로봇
- 기지 방어
- 우주선 수리 준비

Phase 5에서는 기존 EDEN 중심의 게임 세계를 여러 행성으로 확장한다.

플레이어는 불시착한 우주선 ASTRA-01을 수리하고, 항성계를 탐색하며, 새로운 행성에 착륙하여 탐험과 개척을 이어간다.

## 2. 이번 단계의 핵심 플레이 구조

다음과 같은 행성 간 성장 순환 구조를 구현한다.

기지 발전 → 우주선 수리 → 항성계 탐색 → 새로운 행성 착륙 → 환경 적응 → 몬스터 전투 → 희귀 자원 발견 → 새로운 기지 건설 → 행성 간 자원 운송 → 우주선 강화 → 더 먼 행성 탐험

새로운 행성에 도착하는 것은 단순히 새로운 사냥터에 진입하는 것이 아니다.

환경, 중력, 지형, 생명체, 자원, 기술 및 개척 방식이 달라지는 새로운 모험이어야 한다.

기존 행성은 새로운 행성으로 이동하더라도 계속 활용할 수 있도록 한다.

## 3. 기존 프로젝트 분석 및 보호

개발 시작 전 현재 ASTROTOPIA 프로젝트의 실제 구현 상태를 분석한다.

다음 항목을 확인한다.

- 게임 엔진 및 기술 스택
- 캐릭터 이동과 카메라
- 전투 및 몬스터 AI
- 무기와 장비
- 행성 및 지역 데이터
- 환경 위험 시스템
- 자원 채굴
- 정제 및 제작
- 기술 연구
- 기지 건설
- 전력 네트워크
- 자동 생산
- 창고 및 물류
- 우주선 수리 데이터
- 퀘스트 진행 상황
- 저장 시스템

정상적으로 작동하는 기존 기능을 삭제하거나 불필요하게 재작성하지 않는다.

이전 Phase에서 제안되었으나 아직 구현되지 않은 기능이 있다면 Phase 5에 반드시 필요한 기능부터 보완한다.

기존 저장 데이터에 행성 및 우주선 정보가 없는 경우 안전한 기본값을 적용한다.

기존 플레이어의 레벨, 아이템, 장비, 연구 기술, 기지 및 퀘스트 기록을 보호한다.

## 4. 우주선 ASTRA-01 수리 시스템

기존 불시착 우주선 ASTRA-01을 이번 단계의 핵심 목표로 활용한다.

우주선은 다음 7개의 주요 시스템으로 구성한다.

### SYSTEM 01 — HULL

선체

우주선의 구조적 안정성을 관리한다.

필요 부품:

- 강화 선체 패널
- 티타늄 합금
- 구조 연결 부품

### SYSTEM 02 — PROPULSION

추진 장치

우주선의 발사와 행성 간 이동을 담당한다.

필요 부품:

- 추진 장치 부품
- 고밀도 에너지 셀
- 강화 합금

### SYSTEM 03 — NAVIGATION

항법 장치

항성계 지도 및 목적지 탐색을 담당한다.

필요 부품:

- 항법 회로
- 실리콘 웨이퍼
- 외계 회로

### SYSTEM 04 — COMMUNICATION

통신 장치

행성 간 통신과 기지 데이터 확인을 담당한다.

필요 부품:

- 통신 모듈
- 전자 부품
- 에너지 셀

### SYSTEM 05 — LIFE SUPPORT

생명 유지 장치

우주선 내부의 산소 및 거주 환경을 유지한다.

필요 부품:

- 생명 유지 모듈
- 산소 공급 장치
- 생체 폴리머

### SYSTEM 06 — ENERGY CORE

에너지 코어

우주선의 주요 동력원을 담당한다.

필요 부품:

- EDEN TITAN 코어 또는 해당 보스를 통해 해금된 대체 제작품
- 코어 안정화 장치
- 고밀도 에너지 셀
- 고대 에너지 코어 조각

### SYSTEM 07 — LANDING SYSTEM

착륙 장치

행성 착륙과 이륙의 안정성을 담당한다.

필요 부품:

- 강화 착륙 장치
- 티타늄괴
- 제어 회로

각 시스템의 수리 진행률을 개별적으로 관리한다.

이미 Phase 4에서 제작한 부품이 있다면 그대로 사용한다.

기존 보스의 핵심 보상이 다른 퀘스트에서 소비되었더라도 우주선 수리가 영구적으로 막히지 않도록 한다.

## 5. 우주선 관리 화면

명칭:

ASTRA-01 — SHIP STATUS

다음 정보를 표시한다.

- 우주선 이름
- 우주선 등급
- 전체 수리 진행률
- 현재 위치
- 선체 상태
- 추진 장치 상태
- 항법 장치 상태
- 통신 장치 상태
- 생명 유지 장치 상태
- 에너지 코어 상태
- 착륙 장치 상태
- 연료 보유량
- 최대 항해 거리
- 화물 적재량
- 수리 및 업그레이드 가능 여부

각 장치를 선택하면 필요한 재료, 현재 보유 재료, 제작 가능한 시설 및 수리 효과를 확인할 수 있도록 한다.

수리가 완료된 장치는 실제 우주선 기능에 반영한다.

7개 필수 시스템이 모두 정상 상태가 되고 최초 발사 조건을 충족하면 우주선 발사 기능을 활성화한다.

수리하지 않은 우주선이 정상적으로 항해할 수 있는 오류를 방지한다.

## 6. 첫 번째 우주선 발사

우주선 수리가 완료되면 특별한 스토리 이벤트를 진행한다.

이벤트 명칭:

THE FIRST ASCENT

연출 순서:

1. 기지 관제센터에서 발사 준비 알림
2. ASTRA-01 우주선의 주요 시스템 점검
3. 추진 장치 활성화
4. 정착민 및 지원 로봇의 발사 준비
5. 발사 카운트다운
6. 엔진 점화
7. 발사대에서 우주선 상승
8. EDEN의 대기권 진입
9. 우주 공간 도달
10. 항성계 지도 활성화

카메라 이동, 엔진 발광, 입자 효과, 화면 흔들림 및 전용 음악을 활용한다.

첫 번째 발사는 플레이어가 자신의 노력으로 행성을 벗어났다는 성취감을 느낄 수 있도록 연출한다.

약 15~30초 분량을 목표로 한다.

건너뛰기 기능을 제공한다.

반복적인 행성 이동에서는 짧은 발사 연출을 사용한다.

## 7. 우주선 성장 시스템

우주선 역시 캐릭터와 기지처럼 성장하는 핵심 콘텐츠로 구성한다.

### SHIP TIER 1 — ASTRA-01

기초 탐사선

- 가까운 행성 이동
- 소형 화물칸
- 기본 생명 유지 장치
- 제한적인 연료 효율

### SHIP TIER 2 — PATHFINDER

강화 탐사선

- 더 긴 항해 거리
- 확장된 화물칸
- 향상된 추진 장치
- 강화된 환경 대응 성능

### SHIP TIER 3 — HORIZON

중형 개척선

- 여러 행성의 개척 지원
- 대량 화물 운송
- 이동식 제작 시설
- 고급 항법 장치

### SHIP TIER 4 — ODYSSEY

장거리 항해선

- 다른 항성계 이동
- 대형 연구 시설
- 장거리 자원 운송

### SHIP TIER 5 — ASTRO ARK

초대형 개척 모함

- 이동식 우주기지
- 대규모 정착민 운송
- 함대 및 탐사선 지원

Phase 5에서는 ASTRA-01의 완전한 수리와 PATHFINDER 수준의 업그레이드를 실제 구현하는 것을 목표로 한다.

나머지 우주선 등급은 후속 개발을 위한 데이터 구조만 준비한다.

미구현 우주선을 실제 이용할 수 있는 것처럼 표시하지 않는다.

## 8. 우주선 부품 업그레이드

우주선은 전체 등급뿐 아니라 개별 부품을 강화할 수 있도록 한다.

주요 업그레이드 항목:

- 추진 장치
- 연료 저장 장치
- 항법 장치
- 화물칸
- 생명 유지 장치
- 선체 보호 장치
- 에너지 코어
- 환경 분석 장치
- 착륙 장치

업그레이드 예시:

### 추진 장치 MK-II

- 최대 항해 거리 증가
- 연료 소비량 감소

### 화물칸 MK-II

- 최대 화물 적재량 증가

### 항법 장치 MK-II

- 새로운 행성 탐지
- 항해 가능한 경로 확장

### 선체 보호 장치 MK-II

- 위험한 대기 환경에서 착륙 가능

### 고급 생명 유지 장치

- 우주선 내부 회복 효율 증가
- 극한 환경 행성 탐험 지원

업그레이드 전후 능력치를 비교할 수 있도록 한다.

이미 적재한 화물과 기존 우주선의 저장 상태가 업그레이드 과정에서 손실되지 않도록 한다.

## 9. 우주선 내부 탐험

우주선을 단순한 이동 메뉴로만 구성하지 않는다.

플레이어가 실제로 우주선 내부를 횡스크롤 방식으로 이동할 수 있도록 한다.

ASTRA-01 내부는 다음 구역으로 구성한다.

### COCKPIT

조종실

- 항성계 지도 접근
- 목적지 선택
- 우주선 상태 확인
- 출발 및 착륙 제어

### LIVING QUARTERS

거주 구역

- 휴식
- 체력 회복
- 저장
- 개인 장비 관리

### CARGO BAY

화물 구역

- 우주선 화물 관리
- 자원 적재 및 하역
- 행성 간 운송 준비

### ENGINE ROOM

엔진실

- 추진 장치 확인
- 연료 보충
- 에너지 코어 관리
- 우주선 업그레이드

### WORKSHOP

소형 작업실

- 기본 아이템 제작
- 소비 아이템 제작
- 탐험 장비 점검

Phase 5에서는 우주선 내부 구조를 고정형으로 구현한다.

우주선 내부 자유 건설은 후속 단계에서 개발한다.

우주선 내부에는 창밖으로 보이는 우주 및 현재 행성의 배경을 적용한다.

## 10. 항성계 지도

명칭:

SOLARIS STAR SYSTEM

기존 기획에서 정의한 7개의 행성을 지도에 표시한다.

### EDEN

- 녹색 생명체 행성
- 권장 레벨 1~15
- 중력 0.9G
- 상태: 최초 발견 행성

### ARES

- 붉은 사막 행성
- 권장 레벨 15~30
- 중력 0.65G
- 상태: Phase 5 탐험 가능

### FROSTIA

- 극저온 얼음 행성
- 권장 레벨 30~45
- 중력 1.2G
- 상태: Phase 5 후반부 탐험 가능 목표

### INFERNO

- 화산 행성
- 권장 레벨 45~60
- 중력 1.5G
- 상태: 후속 개발 예정

### AQUARIA

- 해양 행성
- 권장 레벨 60~75
- 중력 1.0G
- 상태: 후속 개발 예정

### LUNARIS

- 저중력 위성형 행성
- 권장 레벨 75~90
- 중력 0.2G
- 상태: 후속 개발 예정

### OMEGA

- 고대 외계 문명 행성
- 권장 레벨 90~100
- 중력: 탐사 전 미확인
- 상태: 미확인 신호

행성마다 독창적인 색상과 외형을 적용한다.

항성계 지도는 행성 목록을 단순한 버튼으로 나열하는 방식이 아니라 실제 우주 공간을 탐색하는 느낌을 제공한다.

행성의 공전 연출과 배경 별자리, 이동 경로 표시를 적용할 수 있다.

실제 천체 물리 시뮬레이션을 구현할 필요는 없다.

## 11. 행성 정보 및 목적지 선택

행성을 선택하면 다음 정보를 표시한다.

- 행성 이름
- 행성 이미지
- 행성 분류
- 발견 여부
- 탐험 진행률
- 권장 레벨
- 중력
- 대기 상태
- 평균 기온
- 주요 환경 위험
- 주요 발견 자원
- 알려진 생명체
- 기지 건설 여부
- 필요한 환경 장비
- 필요한 우주선 등급
- 예상 항해 시간
- 예상 연료 소비량
- 현재 착륙 가능 여부

아직 발견하지 않은 행성의 상세 정보는 제한적으로 표시한다.

행성 진입 조건이 충족되지 않았다면 그 이유를 명확히 안내한다.

예시:

ARES 착륙 불가

- 항법 장치 수리 필요
- 방진 헬멧 필요
- 연료 15개 필요

단순히 잠긴 버튼만 표시하지 않는다.

## 12. 행성 간 항해 및 연료

행성 간 이동은 항로 선택과 짧은 항해 연출을 중심으로 구현한다.

이번 단계에서는 실시간 우주선 조종이나 복잡한 우주 비행 시뮬레이션을 필수 범위에 포함하지 않는다.

항해 과정:

1. 우주선 조종실 진입
2. 항성계 지도 열기
3. 목적지 행성 선택
4. 필요한 연료 확인
5. 착륙 조건 확인
6. 화물 적재 상태 확인
7. 항해 시작
8. 짧은 우주 항해 연출
9. 목적지 행성 접근
10. 착륙 지점 선택
11. 행성 착륙
12. 실제 플레이 재개

초기 연료 소비량 예시:

- EDEN ↔ ARES: 15
- ARES ↔ FROSTIA: 25
- EDEN ↔ FROSTIA: 35

위 수치는 실제 게임 밸런스에 맞게 조정한다.

항해 비용은 이동이 부담스러울 정도로 높게 설정하지 않는다.

항해 시간은 약 5~15초를 기본 목표로 한다.

연료는 에너지 결정 및 기존 정제 자원을 활용하여 제작할 수 있도록 한다.

항해 중 새로고침이나 게임 종료가 발생해도 연료가 이중으로 차감되거나 우주선이 사라지지 않도록 처리한다.

## 13. 우주선 연료 및 귀환 안전장치

연료 시스템은 탐험의 전략적 요소이며 플레이어를 영구적으로 고립시키는 시스템이 되어서는 안 된다.

다음 안전장치를 적용한다.

- 출발 전에 목적지 도착 및 귀환 가능 여부 표시
- 목적지에서 확보 가능한 연료 자원 안내
- 각 행성에 비상 연료 확보 수단 제공
- 최초 착륙 시 비상 귀환용 연료 확보
- 비상 연료는 반복적으로 무한 획득할 수 없도록 관리
- 연료 부족 상태에서 스토리 진행이 영구적으로 차단되지 않도록 처리

초기 연료 제작 시설은 EDEN뿐 아니라 새로운 행성의 기초 제작대에서도 사용할 수 있도록 한다.

플레이어가 자신의 기지로 돌아오기 위해 지나치게 많은 반복 채굴을 수행하지 않도록 한다.

## 14. 행성 이동 시 세계 상태 유지

ASTROTOPIA의 모든 행성은 독립적인 월드 상태를 유지한다.

플레이어가 ARES로 이동해도 EDEN에서 건설한 기지와 시설은 사라지지 않는다.

다음 정보를 행성별로 저장한다.

- 발견한 지역
- 퀘스트 진행 상황
- 보스 처치 기록
- 설치한 건물
- 전력 네트워크
- 발전 시설 상태
- 자동 생산 시설
- 창고 자원
- 로봇 및 정착민
- 환경 상태
- 기지 레벨
- 마지막 방문 시간

플레이어 캐릭터는 동일한 캐릭터로 모든 행성을 이동한다.

다음 정보는 행성 공통으로 관리한다.

- 캐릭터 레벨
- 경험치
- 장비
- 보유 스킬
- 인벤토리
- 연구 기술
- 우주선
- 발견 도감

행성별 저장 상태와 캐릭터 공통 상태를 명확하게 분리한다.

## 15. 두 번째 행성 — ARES

행성 이름:

ARES — THE CRIMSON WASTELAND

붉은 황무지.

행성 설정:

- 분류: 사막 및 암석 행성
- 권장 레벨: 15~30
- 중력: 0.65G
- 대기: 희박한 산소 및 미세먼지
- 주간 기온: 높음
- 야간 기온: 낮음
- 주요 위험: 모래폭풍, 산소 부족, 열 노출

ARES는 거대한 붉은 협곡, 사막 평원, 광물 산맥, 지하 동굴 및 오래된 외계 산업 시설이 존재하는 행성이다.

EDEN의 녹색 숲과 완전히 다른 시각적 분위기를 제공한다.

하늘에는 거대한 주황색 항성과 두 개의 암석 위성이 보인다.

지형에는 바람에 의해 이동하는 모래, 붉은 먼지, 침식된 암석 및 고대 금속 잔해가 존재한다.

저중력 환경으로 인해 EDEN보다 점프 높이와 체공 시간이 증가한다.

플레이어는 새로운 조작감을 실제로 체감할 수 있어야 한다.

## 17. ARES 환경 시스템

Phase 3에서 구현한 기존 환경 시스템을 확장한다.

### 저중력

- 점프 높이 증가
- 체공 시간 증가
- 낙하 속도 감소
- 공중 이동의 중요성 증가

### 모래폭풍

일정 시간 동안 발생하는 지역 환경 이벤트.

효과:

- 시야 감소
- 공중 먼지 증가
- 바람 방향에 따른 이동 영향
- 일부 투사체 궤적 변화

모든 무기에 동일하게 바람 영향을 적용하지 않는다.

에너지 광선, 물리 투사체, 근접 공격 등 무기 특성에 따라 차별화한다.

### 고온 노출

특정 지역과 시간에 발생한다.

적절한 냉각 장비를 착용하면 피해를 줄일 수 있다.

### 산소 부족

외부 탐험 중 산소가 점차 감소한다.

우주선 내부, 밀폐된 거주 시설 및 지정된 안전 지점에서는 산소를 회복한다.

### 야간 환경

- 기온 감소
- 시각적 분위기 변화
- 일부 야행성 몬스터 활동
- 태양광 발전 효율 변화

Phase 5에서는 각 환경 요소의 기초적인 작동을 구현한다.

복잡한 극한 환경 시뮬레이션은 Phase 6에서 발전시킨다.

## 21. ARES 대형 보스 — DUNE COLOSSUS

보스 이름:

DUNE COLOSSUS

사막의 거신.

고대 산업 시설 아래에서 발견되는 거대한 사막 생명체와 기계 장치의 융합체다.

- 열에너지 코어
- 발광하는 꼬리

보스는 일반적인 횡스크롤 몬스터보다 훨씬 큰 체형으로 제작한다.

전투 지역은 고대 제련소의 거대한 산업 공간으로 구성한다.

### PHASE A — SAND AWAKENING

체력 100~70%.

공격 패턴:

- 앞발 강타
- 모래 투사체
- 지면 진동
- 느린 돌진

### PHASE B — DESERT STORM

체력 70~35%.

공격 패턴:

- 모래폭풍 발생
- 지면 잠복 후 등장
- 다중 충격파
- 꼬리 에너지 공격
- 소형 사막 생명체 소환

플레이어는 저중력 점프와 공중 추진을 활용하여 위험 지역을 회피한다.

### PHASE C — OVERHEATED CORE

체력 35~0%.

공격 패턴:

- 열에너지 광선
- 광역 지면 폭발
- 연속 돌진
- 과열된 코어의 에너지 방출

강력한 공격 이후 열에너지 코어가 노출된다.

코어 공격 시 추가 피해를 제공한다.

모든 위험한 공격은 명확한 예고를 제공한다.

모래폭풍 중에도 필수 공격 예고가 완전히 가려지지 않도록 한다.

보스 처치 보상:

- DUNE COLOSSUS 코어
- 고대 산업 데이터
- 고급 추진 장치 설계도
- 내열 합금
- 희귀 및 영웅 등급 장비
- ARES 개척자 칭호

첫 처치 보상과 반복 처치 보상을 구분한다.

- 분류: 극저온 얼음 행성

- 중력: 1.2G
- 대기: 호흡 불가능
- 평균 기온: 극저온
- 주요 위험: 동결, 산소 부족, 눈보라, 빙판

FROSTIA는 끝없이 펼쳐진 얼음 평원과 거대한 빙하, 수정 동굴 및 얼음 속에 잠들어 있는 고대 연구 기지로 이루어진 행성이다.

EDEN의 생명력과 ARES의 붉은 황무지와 완전히 다른 차갑고 신비로운 분위기를 제공한다.

하늘에는 오로라와 멀리 보이는 푸른 위성을 표현한다.

Phase 5에서 ARES의 핵심 콘텐츠가 안정적으로 작동한 이후 FROSTIA를 구현한다.

전체 범위를 완성하기 어렵다면 FROSTIA는 첫 번째 착륙 지역과 기초 탐험까지 구현하고 나머지 콘텐츠를 Phase 6으로 이관한다.

기존 맵의 점프 난이도가 중력 변경으로 인해 불합리해지지 않도록 행성별 지형을 함께 조정한다.

## 30. 캐릭터 성장 범위 확장

기존 EDEN의 권장 레벨은 1~15로 유지한다.

새로운 성장 범위:

- EDEN: 레벨 1~15
- ARES: 레벨 15~30
- FROSTIA: 레벨 30~45

Phase 5의 목표 최대 레벨은 45다.

FROSTIA가 부분 구현되는 경우 실제 콘텐츠 범위에 맞춰 레벨 진행을 조정한다.

레벨업에 따라 다음 요소를 강화한다.

- 체력
- 에너지
- 공격력
- 방어력
- 환경 저항
- 장비 착용 가능 등급
- 탐험 기술

기존 무기와 스킬을 유지한다.

정식 직업 전직과 대규모 스킬 트리는 Phase 7의 핵심 콘텐츠로 유지한다.

레벨 상승이 단순한 수치 인플레이션으로 이어지지 않도록 한다.

기존 EDEN 지역으로 돌아왔을 때 기존 콘텐츠가 정상적으로 작동해야 한다.

## 33. 우주선 화물 시스템

플레이어 인벤토리와 별도의 우주선 화물칸을 구현한다.

ASTRA-01 초기 화물 용량은 80칸을 기준으로 한다.

화물칸 업그레이드에 따라 용량을 확장할 수 있도록 한다.

예시:

- 기본 화물칸: 80칸
- 확장 화물칸: 160칸
- 산업 화물칸: 320칸

화물 관리 기능:

- 인벤토리에서 화물칸으로 이동
- 행성 창고에서 화물칸으로 이동
- 화물칸에서 행성 창고로 이동
- 수량 선택
- 동일 자원 자동 정리
- 화물 용량 확인
- 특정 자원 검색

우주선 화물은 행성 간 이동 시 그대로 유지된다.

기지 창고와 우주선 화물칸은 서로 독립적으로 관리한다.

아이템이 두 창고에 동시에 존재하거나 이동 도중 사라지는 오류를 방지한다.

## 34. 행성 간 자원 운송

Phase 5에서는 수동 운송과 제한적인 자동 운송 시스템을 구성한다.

### TIER 1 — MANUAL TRANSPORT

수동 운송

플레이어가 직접 우주선 화물칸에 자원을 적재한 후 다른 행성으로 이동한다.

이 기능은 이번 단계의 필수 구현 범위다.

### TIER 2 — AUTOMATED CARGO ROUTE

자동 화물 항로

특정 연구 기술과 우주선 부품을 확보한 이후 제한적으로 자동 운송을 설정할 수 있다.

운송 항로 데이터:

- 출발 행성
- 도착 행성
- 운송 자원
- 운송 수량
- 운송 주기
- 연료 소비량
- 최소 보유 자원
- 도착 창고 상태

초기 자동 운송 항로는 최대 2개를 기준으로 한다.

자동 운송은 별도의 자원 복제 기능이 아니며 출발지에서 실제 자원을 차감하고 도착지에 지급한다.

운송 중인 화물은 별도의 상태로 관리한다.

도착 창고가 가득 찼다면 화물을 대기시키거나 출발지로 반환한다.

자동 운송이 불완전하다면 수동 운송을 우선 완성하고 자동화는 Phase 9로 이관한다.

## 35. 행성 간 생산 연동

플레이어가 다른 행성을 탐험하는 동안 기존 행성의 산업 시설도 제한적으로 생산을 계속하도록 한다.

기존 Phase 4의 자동 생산 시스템을 재사용한다.

다른 행성의 생산을 위해 모든 행성의 게임 Scene과 몬스터를 동시에 실행하지 않는다.

대신 행성별 산업 시뮬레이션 데이터를 활용한다.

생산 계산에 다음 요소를 반영한다.

- 발전량
- 소비량
- 축전지 상태
- 발전기 연료
- 입력 재료
- 생산 목표량
- 창고 공간
- 시설 작동 상태
- 해당 행성의 환경 조건

행성 이동 시 생산량이 초기화되거나 중복 계산되지 않도록 한다.

플레이어가 없는 행성에서 몬스터 침공이 발생하여 기지가 파괴되는 시스템은 구현하지 않는다.

오프라인 생산 시간의 상한은 기존 Phase 4의 설정을 유지한다.

## 45. 성능 최적화

다중 행성 콘텐츠가 추가되더라도 기존 게임의 성능을 유지한다.

- 현재 플레이 중인 행성의 Scene만 실제 렌더링
- 방문하지 않은 행성의 몬스터 AI 실행 제한
- 다른 행성은 경량 산업 시뮬레이션만 처리
- 행성 전환 시 불필요한 에셋 및 객체 정리
- 필요한 행성 에셋만 동적으로 로딩
- 전력 네트워크의 불필요한 재계산 방지
- 자동 생산 계산의 중복 실행 방지
- 우주선 이동 시 저장 상태 검증
- 파티클 오브젝트 풀링
- 메모리 누수 방지

모든 행성의 대형 맵과 몬스터를 동시에 활성화하지 않는다.

일반적인 PC 웹 브라우저에서 안정적인 60FPS를 목표로 한다.

실제 측정하지 않은 성능을 달성했다고 보고하지 않는다.

## 46. 개발 및 밸런스 원칙

새로운 행성으로 이동할 때 플레이어가 기존 시스템을 처음부터 다시 반복해야 하는 구조를 지양한다.

다음 원칙을 적용한다.

- 새로운 행성에서도 기존 장비 사용 가능
- 기존 연구 기술 유지
- 기존 기지 유지
- 기존 캐릭터 레벨 유지
- 새로운 행성에서는 특수 환경과 자원에 집중
- 기초 기지 건설에 필요한 최소 자원 확보 지원
- 우주선을 통한 행성 간 자원 이동 제공
- 기존 장비가 한순간에 무용지물이 되지 않도록 조정
- 기존 행성을 계속 방문할 이유 제공
- 새로운 행성의 특성이 플레이 방식에 실제로 반영

레벨업과 자원 수집을 위해 동일한 몬스터를 지나치게 많이 반복 처치하는 구조를 지양한다.

탐험, 퀘스트, 보스 공략, 연구 및 기지 발전을 통해서도 자연스럽게 성장할 수 있도록 한다.

## 50. 최종 개발 지시

Phase 5의 목적은 ASTROTOPIA를 하나의 행성에서 진행되는 RPG에서 실제로 여러 행성을 탐험하고 개척할 수 있는 SF 우주 RPG로 발전시키는 것이다.

플레이어가 오랜 노력으로 우주선을 수리한다.

첫 번째 행성을 벗어나 우주 공간에 도달한다.

항성계 지도를 통해 새로운 세계를 발견한다.

새로운 중력과 환경에 적응한다.

처음 보는 생명체와 싸운다.

희귀 광물을 채굴하고 새로운 기술을 연구한다.

두 번째 행성에 자신의 기지를 건설한다.

서로 다른 행성의 자원을 연결하고 더욱 발전된 우주선을 제작한다.

이 모든 과정이 하나의 자연스러운 게임 플레이 흐름으로 이어져야 한다.

가장 중요한 우선순위는 다음과 같다.

1. 기존 게임의 안정성
2. 첫 번째 우주선 발사의 성취감
3. 자연스럽고 안정적인 행성 이동
4. 행성마다 완전히 다른 탐험 경험
5. 새로운 환경과 중력의 실제 체감
6. 다중 행성 기지의 지속적인 운영
7. 행성 간 자원 운송
8. 장기적인 콘텐츠 확장성

설계 문서만 작성하고 종료하지 않는다.

실제 실행 가능한 게임 코드와 콘텐츠를 구현한다.

작동하지 않는 메뉴와 가짜 기능을 완성된 콘텐츠처럼 표시하지 않는다.

개발 완료 후 다음 내용을 한국어로 보고한다.

- 구현 완료 기능
- 기존 시스템 개선 사항
- 우주선 수리 시스템
- 항성계 지도
- 행성 이동 방식
- 실제 탐험 가능한 행성
- 신규 탐험 지역
- 신규 몬스터
- 신규 보스
- 신규 자원 및 장비
- 행성별 중력 및 환경
- 다중 행성 기지 운영
- 화물 운송 시스템
- 주요 변경 파일
- 저장 데이터 호환 여부
- 자동화 테스트 결과
- 실제 브라우저 플레이 테스트 결과
- 성능 측정 결과
