# ASTROTOPIA — Phase 5 · BEYOND EDEN

Phaser 3 + TypeScript + Vite 기반 2D 우주 탐험 RPG입니다. 기존 EDEN 전투·생존·산업에 우주선, ARES, 행성별 기지와 수동 화물 운송을 연결했습니다.

## 실행

```powershell
npm install
npm run dev
```

개발 미리보기: http://127.0.0.1:5180 (strict port). `npm run build`, `npm test`, `npm run test:e2e`, `npm run test:production`으로 검증합니다. 게임은 상대 URL만 사용하며 외부 도메인 설정이 필요하지 않습니다.

## 우주선 수리와 항해

1. Phase 4의 우주선 부품 납품과 코어 분석을 완료하세요. L 연구에서 **기초 우주선 수리**와 **사막 환경 분석**을 연구합니다.
2. 착륙선 근처에서 U → 이전 납품 기록 점검. 이미 납품한 6개 부품은 다시 소비하지 않습니다. 착륙 장치는 티타늄괴 2 + 전자 부품 1로 제작해 수리합니다. 별도 코어 복원이 필요하면 EDEN TITAN 처치 후 복원 코어를 제작할 수 있습니다.
3. 선체·추진·항법·통신·생명 유지·코어·착륙 장치, 총 7개를 복구하세요. 항해 연료는 결정 1 + 구리 1로 5개를 제작합니다.
4. 방진 헬멧과 산소 장비를 C에서 장착한 뒤 우주선에 탑승하세요. U → 항성계 지도 → 첫 이륙. 최초 연출 20초, 이후 항해 8초이며 건너뛸 수 있습니다.
5. 첫 이륙은 연료 5, EDEN↔ARES는 편도 15를 사용합니다. 출발 시 한 번만 차감하며 항해 중 종료해도 이어집니다. ARES 첫 착륙에 한해 귀환 연료 15를 지급합니다. 이후 사막 결정 1 + 붉은 철 1로 연료 5를 만들 수 있어 현지에서 귀환을 준비할 수 있습니다.

우주선 내부는 조종실, 생활실, 화물실, 기관실, 작업실의 다섯 구역입니다. 선내에서는 자동 회복하고 U로 항해·화물·강화 기능을 사용합니다. 비상 연료 제작은 전력을 요구하지 않습니다. 항해 중에는 생산 시뮬레이션만 진행합니다.

## ARES 탐험과 개척

착륙 분지 → 붉은 모래언덕 → 강철 협곡 → 고대 제련소 순으로 F 표지를 이용합니다. 실제 중력은 0.65G입니다. 야외 산소 소비, 열 노출, 예고 후 시작되는 모래폭풍, 물리 탄환에 작용하는 바람을 확인하세요. 방진 헬멧, 사막 탐험복, 냉각 모듈, 안정화 부츠, 고급 산소 장비가 각각 대응합니다.

8종의 새 생명체와 3단계 DUNE COLOSSUS가 등장합니다. 제련소의 산업 기록을 조사하고 동쪽 호출 지점에서 보스에 도전하세요. 지면 예고, 광선과 돌진을 피하고 코어 노출 때 반격합니다. 첫 처치의 산업 데이터·추진 설계도로 PATHFINDER를 연구하고 추진·화물·항법·선체·생명 유지 장치를 강화합니다. 최대 레벨은 최초 이륙 후 30입니다.

착륙 분지에서 B를 누르면 기존 건설 도구로 새 기지를 만듭니다. EDEN 창고와 ARES 창고는 별개입니다. 기본 태양광·산소·거주·채굴·정제·창고 외에 방진 보호막, 온도 조절기, 고효율 태양광, 사막 채굴기를 사용할 수 있습니다. 환경 보호 시설은 연결된 전력이 필요합니다.

U → 화물 운송에서 인벤토리/현지 창고와 우주선 화물을 이동합니다. 기본 80칸, 강화 후 160칸입니다. 자원을 실어 다른 행성으로 항해한 뒤 현지 창고에 내려놓으세요. 원격 행성은 적 AI 없이 기존 산업 로직으로 생산하며, 실제 연료·전력·입력 재료·출력 공간을 사용합니다. 오프라인 상한은 행성별 4시간입니다. 행성 간 통신 연구 후 U → 행성 기지에서 원격 가동을 전환할 수 있습니다.

## 조작과 저장

A/D 이동, Space 점프, Shift 대시, J/K 기본/특수 공격, F 상호작용, C 장비, L 제작·연구, B 건설, O 기지, U 우주선, I 인벤토리, M 지역 지도, Esc 일시정지.

저장은 기존 브라우저 키를 유지하는 버전 5입니다. 버전 1~4를 마이그레이션하고 이전 버전 원본을 백업합니다. 플레이어와 연구는 공유하되 각 행성의 시설·창고·생산 대기열·채굴 쿨다운을 분리합니다. 항해·화물·수리·최초 착륙 보상 상태도 저장합니다. 저장소를 삭제하면 진행을 복구할 수 없습니다.

## 범위

실제 탐험 가능한 행성은 EDEN과 ARES입니다. 항성계 지도에는 7개 행성이 표시되며 나머지 행성은 잠금 사유를 안내합니다. FROSTIA는 이어지는 Phase 6에서 완성합니다. 자동 화물 항로, 우주 항해 랜덤 이벤트, ODYSSEY/ARK는 후속 콘텐츠입니다. 원격 건설·수리는 지원하지 않습니다.
