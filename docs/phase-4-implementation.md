## 업그레이드

시설 Lv.1→2에는 산업 자동화, Lv.2→3에는 첨단 개척 연구가 필요합니다. 비용은 현재 레벨 × 철괴 3, 현재 레벨 × 전자 부품 1입니다. 단계마다 생산 속도 +30%, 발전량 +35%, 기본 저장 용량 1배 추가, 소비 전력 −8%, 내구도 +50%, 포탑 피해 +30%를 해당 기능에 적용합니다. 거주 수용은 레벨당 2명, 축전지는 레벨당 200 EU·s/충·방전 20 EU입니다. 강화는 즉시 적용하며 진행 중 재료·완성품·저장 자원을 유지합니다.

## 연결과 자동 생산

발전기와 중계기의 원형 공급 범위로 전력망을 묶습니다. 소비 시설은 도달 가능한 가장 가까운 공급원의 망 하나에 연결되며 다른 망을 연결하는 중계 역할은 하지 않습니다. 기본 반경은 360, 플라즈마 440, 코어 발전기 520입니다. 망은 설치·철거·정지·복구 시 재계산합니다. 전력 배분과 생산은 0.25초 주기로 계산합니다. 생존 1, 방어 2, 산업·연구 3, 편의 4순위이며 시설별 조정이 가능합니다.

창고 반경 480 안의 시설은 중앙 자원을 공유합니다. 전력 공급 중인 중앙 물류 관리소가 있으면 전체 기지로 확장합니다. 가방·개인 창고·기지 창고는 별도 자원을 복제하지 않습니다. 자동 작업은 중앙 창고만 사용하며 수동 제작과 건설은 기지에서 가방과 창고를 함께 사용합니다.

채굴은 철 10초, 구리 12초, 실리콘 15초, 결정 20초, 티타늄 25초, 석탄 12초가 기본입니다. MK-II는 1.5배, 레벨·연구·전문가·로봇 보너스를 추가합니다. 매장지 밖 설치와 MK-I 티타늄 채굴은 거부합니다. 스토리 보상은 자동 채굴하지 않습니다.

자동 정제·부품 생산은 기존 Phase 3 레시피를 사용합니다. 창고 목표까지 반복 보충 / 이번 목표 수량 생산, 최소 보유량, 우선순위를 설정할 수 있습니다. 재료는 작업 시작에 보관하고 완성품 저장 후에만 작업을 종료합니다. 공간 부족 시 완성 작업을 유지하며 취소·재설정·철거의 반환도 공간 확인 후 한 번에 처리합니다. 코어 안정기는 고유 자원 보호를 위해 1개씩만 생산합니다.

## 성장·방어·지원

기지 레벨은 시설 종류·연구·거주·발전·수리 준비 상태로 결정합니다. 건물 수만 늘려 레벨을 올리지 않습니다. EDEN은 호흡 가능한 환경이며 정착민은 전력과 같은 망의 산소 공급이 갖춰진 거주 모듈을 사용합니다. 정착민 5직업, 최대 10명이며 배치된 시설에 보너스를 제공합니다. 생계·정치·사회 시뮬레이션은 없습니다.

지원 로봇은 채굴 보조·수리·탐사 3종, 최대 20대입니다. 호버 이동으로 지상 장애물을 피하고 작업·복귀·충전·전력 대기를 수행합니다. 수리는 철괴를 소비하고 탐사는 일반 연구 데이터만 생산합니다. 물류 로봇은 미구현입니다.

침공은 레이더에서 직접 시작하고 30초 준비 뒤 지상 개체와 강화 갑충이 도착합니다. 포탑은 기존 CombatSystem 피해 판정을 사용하고 침공 적만 조준합니다. 냉각·보호막·방어벽·수리가 작동합니다. 시설 HP 0은 정지이며 자원과 건물을 삭제하지 않습니다. 사망·지역 이탈·중단 시 안전 종료합니다. 반복 침공은 기본 꺼짐, 첫 승리만 보상하며 포탑 전투 경험치 파밍을 막습니다. 공중·독성·복수 유형 침공은 확장 범위입니다.

## 저장·오프라인·Phase 5

저장 v4, 기존 키 astrotopia.save.v1 유지. v1/v2/v3 이관과 1회 백업, 기존 장비·임무·시설 보존. 좌표·ID·재료 보관·연구·건물·정착민·로봇·부품 납품을 검증합니다. 전력망과 기지 레벨은 저장 상태에서 다시 계산합니다. 침공 중 공격 패턴을 재개하지 않습니다.

오프라인은 최대 4시간, 1초씩 최대 14,400회로 제한하여 실제 연료·배터리·전력·재료·창고·목표를 적용합니다. 태양광은 낮 비율 60% 평균으로 계산합니다. 공격·건물 피해·정착민 사망은 없습니다. 시계 역행은 0초이며 마지막 처리 시각을 유지합니다. 저장 전체 되돌리기나 기기 시각 위조까지 막는 서버 권한 시스템은 아닙니다.

ASTRA-01의 선체·추진·항법·통신·생명 유지·코어 6종 부품과 고대 코어 분석·항법 연구가 Phase 5 진입 준비 상태로 저장됩니다. 실제 발사와 다른 행성 이동은 없습니다. 지역 연결과 환경 데이터는 기존 7개 탐험 지역을 유지합니다.

## 선택 기능 및 한계

컨베이어·분배기·물류 드론·물류 로봇·외부 채굴 전초기지는 미구현입니다. 새 매장지는 초기 기지 확장 구역에 배치했습니다. 구조물은 금속 발판·방어 배리어·조명을 우선 구현했으며 자동문·사다리·독립 지하 구역·복잡한 건축 지지 구조 해석은 없습니다. 방어벽은 탐험가 통행을 막지 않는 배리어입니다. 녹색/빨간 미리보기와 문구, 핵심 시설·자원 보호, 겹침·지지·매장지 조건을 적용합니다.

전체 100건물 렌더링 시험과 실제 20로봇·10정착민·30자동생산·15포탑 복합 장시간 스트레스 시험은 구분합니다. 후자는 아직 완료를 주장하지 않습니다. 실제 스피커 청취, Firefox/Safari, 장시간 수동 경제 밸런스는 미검증입니다.
