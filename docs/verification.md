# Phase 2 검증 기록

2026-11-26 / Windows / Chrome / TypeScript + Vite + Phaser Canvas.

- npm test: 48개 통과. 기존 40개 회귀와 저장 v1→v2, 장비 능력치, 훈련 복원, 상태 이상, 가방 초과 드롭 보존, 약점·경직 제한, 타이탄 13패턴·첫 보상, 저장 입력 검증을 포함합니다.
- 개발 Chrome 통합 시나리오 4개 통과(기존 3개 + 신규 전투 1개, 신규 시나리오 개별 재실행). 훈련 실제 J 입력, C/V 메뉴, 보스 3페이즈 화면 및 안전 재접속을 확인했습니다.
- 프로덕션 Chrome 시나리오 1개 통과. 전체 24초 오프닝, 이동·점프·조사, 메뉴, 저장, 배포 번들의 개발 훅 제거를 확인했습니다.
- npm run build 성공. 테스트 중 콘솔 오류 없음.
- 시작 지역에서 실제 Canvas 출력 5초 샘플: 99.60 FPS, 프레임 간격 p95 13.5ms. 고효과 1440×900, 최대 120FPS 설정. 보스·장시간·다른 하드웨어의 성능 보장 수치가 아닙니다.
- 시각 검사에서 보스 화면 잘림을 발견해 전투 중 카메라를 투기장에 고정했고, 메뉴 위 알림 겹침을 숨겼습니다.

## 검증 범위의 한계

브라우저 테스트는 긴 이동과 레벨업을 줄이기 위해 개발 전용 상태 준비를 사용합니다. 일반 난이도로 새 게임부터 마지막 보스까지 수작업 완주한 기록은 아닙니다. 모든 무기의 장시간 체감 밸런스, 실제 스피커 청취, Firefox/Safari, 모바일·게임패드, 키 재배치는 검증 또는 구현되지 않았습니다. 생산 기능은 아직 Phase 3 작업 대상입니다.

Phase 1 기록은 phase-1-verification.md, 원문은 phase-1-brief.md와 phase-2-brief.md입니다. 스크린샷은 artifacts/phase-2-equipment.png와 phase-2-titan.png에 있습니다.
