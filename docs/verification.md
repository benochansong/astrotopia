# Phase 7 구현 및 검증 보고서

기반: Phase 6 커밋 `85283d1`. 작업 브랜치: `codex/phase-7-path-of-the-explorer`. 기존 Phaser Canvas, TypeScript, Vite와 전투·이동·산업·저장 시스템을 확장했습니다. 도메인·DNS·배포 설정은 변경하지 않았습니다.

## 구현

- 6개 기본 직업, 12개 2차 전문화 및 대응하는 3차 직업. Lv.10/30/60 전직, 기존 고레벨 순차 전직.
- 기본 액티브 24종, 전문화 액티브 36종, 궁극기 12종, 패시브 노드 18종. 스킬 카탈로그의 각 효과가 기존 CombatSystem·투사체·상태 이상·플레이어 물리에 연결됩니다.
- SP 소급 지급, 최초 전직 보너스, 선행 기술·레벨·직업 검증, 3개 성장 분야, 일반 최대 5단계 및 숙련 패시브 최대 10단계.
- 공통 스킬 6종 유지. 같은 Q/E/R/T 슬롯에 직업 또는 공통 스킬 배치. 기존 U 우주선·H 회복을 보존하고 궁극기는 6으로 배치.
- 직업 게이지 100, 실제 적 피해 기준 지급 상한, 훈련 인형 제외, 환경 피해로 반격·불굴 충전 금지, 궁극기 재사용 및 EP 비용.
- 드론·포탑·함정 최대 4개, 위치·사거리·내구·수명·공격 간격. 메카는 기존 플레이어 충돌을 유지하는 외골격 태세.
- 직업별 기본 능력치·추천 무기 숙련·콤보·표식·속성 전환·중력 흡인·회복·반격·제트/수중 추진.
- Guardian 시설 방어, Ranger 전투 XP, Engineer 건설/생산, Scientist 연구 RP, Explorer 환경/채굴/추진, Cyber Blade 검 전투 XP. 현재 직업의 보너스만 적용하며 개척 기본 보조 상한 15%.
- 직업별 몸통·코어 장비 총 12개, 희귀/영웅 제작, 기존 강화·장착과 환경 모듈 병용. 신입의 일반 전리품에 고급 직업 장비가 섞이지 않도록 제한.
- 무료 초기 전직 터미널, 건설 가능한 PIONEER ACADEMY, 서로 다른 장비 실루엣과 대화가 있는 교관 6명.
- 독립 체험 월드, 180초 시험, 직업별 추가 목표, 4개 등급, 최초 등급 향상 보상. 원본 상태는 별도 보관하며 체험 중 저장도 원본을 사용.
- 직업별 숙련 Lv.20, 비용을 동반한 변경·초기화, 보스/위험/침공 중 변경 금지, 숙련 보존, 보상 중복 방지.
- 스킬·무기·전투 장비·환경 모듈 프리셋 6개. 보유 장비만 적용하고 HP·EP·산소와 재사용 시간을 복구하지 않음.
- 별도 진행하는 직업 퀘스트 57~64, LUNARIS GENESIS 기록과 연결. 기존 메인 퀘스트 순서를 바꾸지 않음.
- 실제 처치한 기존 보스 7개 재도전, NORMAL/HARD/MASTERY. 추가 추적 중력장과 교차 광선, 최초 성공 보상, 원본 스토리 코어 중복 지급 방지.
- 직업 선택/비교, 스킬 트리, 숙련·프리셋, 훈련·재도전 탭. 직업 HUD·게이지·궁극기 대기 시간, 기본/장비/기타 능력치 상세.
- 직업별 절차적 장비 레이어, 드론/포탑, 표식, 기존 합성 사운드와 공격 예고 재사용.

## 저장 호환

버전 7. 버전 1~6 변환 및 이전 버전 백업. 기존 캐릭터·장비·강화·공통 스킬·재료·연구·기지·우주선·행성·퀘스트를 보존합니다. 직업, 전문화, 최고 전직 단계, 지급 SP, 스킬 단계·슬롯·쿨다운·게이지, 직업별 숙련, 시험 등급, 퀘스트 수령 기록, 변경 횟수·대기, 프리셋을 검증합니다.

SP는 레벨·최고 전직·수령한 퀘스트에서 계산합니다. 중복 전직이나 반복 로드로 지급량이 늘어나지 않습니다. 소유하지 않은 직업 스킬 슬롯은 기존 공통 슬롯으로 복구하며, 잘못된 스킬 단계·과도한 SP 소비·NaN·범위 초과를 거부합니다. 체험 장비·경험치·재화가 실제 데이터에 들어가지 않는 경계를 테스트했습니다.

검증은 실제 실행한 결과로 아래에 기록합니다. 수동 전체 캠페인 완주나 장시간 밸런스 테스트를 수행했다고 주장하지 않습니다.

- 기존 회귀 및 직업 단위·통합 테스트: **149/149 통과** (10개 파일).
- 개발 Chrome 전체 브라우저 테스트: **20/20 통과**. 실제 키 입력으로 레인저 체험을 통과하고 전직·SP 사용·저장·새로고침 복원. 모든 6개 직업의 스킬과 12개 궁극기 실행, 수중/저중력, 기존 건설·항해·전투·환경·설정 검증.
- 프로덕션 Chrome 전체: **4/4 통과**. 개발 훅 없이 고급 전직·궁극기·전용 장비 제작·저장된 재사용 시간 복원, 기지 건설, 실제 행성 항해, 오프닝/이동.
- 타입 검사 및 Vite 프로덕션 빌드 성공. 앱 JS 450.79 kB / gzip 158.52 kB, Phaser 1,208.06 kB / gzip 332.17 kB.

## 제한과 후속 작업

- 여섯 교관은 대화 카드·초상으로 제공하며 독립적인 월드 NPC 경로 탐색은 없습니다.
- 체험/전직/직업 도전은 공유 훈련 맵과 직업별 목표를 사용합니다. 보호 대상 AI·이동 약점 표적·여섯 독립 던전은 추가 확장 영역입니다.
- 모든 고급 스킬·궁극기는 실행되지만 일부는 같은 효과 계열을 재사용합니다. 각 최종 직업을 독립적인 애니메이션 엔진으로 제작하지 않았습니다. 정밀한 기술별 고유 애니메이션과 직업별 장시간 밸런스 조정은 추가 작업입니다.
- 지원 스킬은 플레이어·소환체·근처 시설에 적용하는 싱글플레이 범위입니다. 파티/멀티플레이는 없습니다.
- 훈련 계측은 세션 피해·DPS·치명타·EP·게이지·궁극기·피해 감소·회복·소환 피해를 표시합니다. 여섯 직업의 동일 조건 장시간 DPS 비교표나 전 구간 수동 보스 완주 기록은 아닙니다.
- OMEGA 실제 탐험·GENESIS ZERO·엔딩·Lv.100은 이 보고서 범위에 포함하지 않으며 사용자가 이어서 요청한 Phase 8에서 구현합니다.
