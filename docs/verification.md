# Phase 6 검증 및 구현 보고서

기준 날짜: 2026-11-27 (Asia/Seoul). 기반 커밋은 Phase 5 `8852c07`, 작업 브랜치는 `codex/phase-6-extreme-worlds`입니다.

## 기존 프로젝트 분석과 구현 방식

기존 Phaser Canvas 렌더러, 1/120초 이동 하위 스텝, 공격·상태 이상·투사체 풀, 제작 대기열, ColonySystem, 행성별 SpaceSave를 확장했습니다. 행성마다 별도 물리·산업 엔진을 복제하지 않았습니다. 현재 행성만 적 AI와 화면을 실행하고 원격 행성은 기존 산업 규칙으로 계산합니다. 기존 EDEN·ARES 콘텐츠와 무기·스킬을 유지했습니다.

Phase 5 완료 상태에는 FROSTIA 실제 콘텐츠가 없었으므로 이번 단계에서 네 구역과 보스까지 구현했습니다. 출발 연구·장비의 재료가 도착 이후 행성에만 존재하는 순환 조건을 피하도록 제작 경로를 구성했습니다.

## 저장 호환과 중복 방지

브라우저 키 `astrotopia.save.v1`을 유지합니다. 저장 버전 1~5를 순차 변환하고 저장 시 이전 버전 원본 백업을 유지합니다. 연구·플레이어는 공통, 기지·창고·생산·채굴 쿨다운은 행성별입니다. 환경 수치, 프리셋, 차량·화물, 보스·연구·GENESIS·임무 상태를 포함합니다.

보스 전투 중 재접속은 패턴을 재개하지 않습니다. 수중·공중 재접속은 해당 구역 안전 진입 지점으로 이동하고 산소를 회복하며 추진 에너지 최소 50%를 확보합니다. 항해 중 저장은 출발 연료를 다시 차감하지 않습니다. 최초 항법·설계도·전설 보상을 반복 지급하지 않습니다. 손상된 수치, 알 수 없는 ID, 중복 슬롯, 과적 화물, 잘못된 키 설정은 검증에서 거부합니다.

## 수정한 결함

- ARES 상공 우주선 저장을 읽을 때 EDEN 환경으로 오프라인 계산하던 초기화 순서 수정.
- 원격 생산 반복 대상이 EDEN/ARES로 한정되던 부분을 방문한 여섯 행성으로 확장.
- 보호 시설이 다른 탐험 구역 또는 다른 수심에 적용되던 수평 거리 전용 판정을 구역·높이 조건으로 수정.
- 신규 행성 착륙에도 EDEN 귀환 기록을 주던 분기 수정.
- 지도 안내는 목적지별 비용인데 실제 차감은 ARES 비용을 사용하던 항해 연료 결함 수정.
- 심해 보스 전리품의 수심 저장, 전설 등급·새 칭호·양자 강화 저장 검증 확장.
- 양자 연구소의 연구 시작 조건, 생물 농장 레시피 저장, 해양 창고 저장 용량 계산 연결.
- 보스 체력바와 기지 상단 표시의 겹침 제거, 다른 행성의 EDEN 전경 식물 제거.
- 프리셋 적용 시 사라진 장비를 건너뛰고 변경된 최대 체력·에너지·산소에 맞춰 상한을 조정.

## 자동 검증

- `npm test`: **113/113 통과**, 9개 테스트 파일.
- `npm run build`: TypeScript 및 Vite 프로덕션 빌드 통과. 애플리케이션 JS 약 397 kB / gzip 139 kB, Phaser 별도 청크 약 1,208 kB / gzip 332 kB.
- 개발 브라우저: **17개 시나리오 확인**. 전체 실행 15개 통과 후, 잘못된 일시정지 해제 선택자를 수정한 접근성 1개와 추가 차량 UI 1개를 재실행하여 모두 통과했습니다. 초기 실패는 일시정지 상태에서 이동을 검사한 테스트 절차 오류였습니다.
- 프로덕션 브라우저: **3/3 통과**. 기존 기지 건설, 디버그 훅 없는 HORIZON의 AQUARIA→LUNARIS 항해·실제 조작·저장, 오프닝·기본 조작·렌더링을 확인했습니다.
- 신규 행성 브라우저 시나리오에서 페이지 실행 오류 0건. 프리셋·차량·탐험 관리 화면과 수중·달 보스 스크린샷을 확인했습니다.
- 빌드 산출물에는 개발용 `window.__ASTRO__`가 노출되지 않음을 확인했습니다.

### 실제 성능 측정

Chrome 로컬 개발 환경에서 행성별 5초씩 실제 World.update 호출을 계수했습니다. AQUARIA **98.39 FPS**(492회), LUNARIS **96.57 FPS**(483회)였습니다. 별도 requestAnimationFrame 빈도는 약 234/238Hz이며 게임 FPS와 구분합니다. rAF 간격 p95는 두 장면 모두 4.3ms였습니다. 프로덕션 기본 장면의 Canvas 렌더링 측정은 **98.20 FPS**, 프레임 간격 p95 **14.9ms**였습니다.

여섯 행성 방문 초기화 후 60회 행성 전환·스냅샷을 반복하고 강제 GC 전후를 비교했습니다. 사용 힙 **8,252,320 → 8,300,308 bytes**, 증가 **47,988 bytes (약 46.9 KiB)**입니다. 짧은 반복 전환의 보존량 확인이며 장시간 메모리 누수가 없다고 증명하는 검사는 아닙니다. 측정 환경 밖의 기기에서 동일 FPS를 보장하지 않습니다.

## 제한·미구현·Phase 7 준비

- 2D 프로토타입 규모의 지역·생명체 그래픽과 데이터 기반 보스 패턴입니다. 장시간 밸런스·전체 난이도별 클리어 시간 검증은 별도입니다.
- 원격 행성 기상은 마지막 상태를 사용하는 생산 근사이고 실시간 대기 시뮬레이션은 아닙니다. 해류와 중력장은 해석적 힘 모델입니다.
- 수중 굴절 셰이더, 자유 깊이 건축, 전용 내열 로버·달 호버, 차량 간 다중 차고는 미구현입니다. 활성 차량은 1대입니다.
- 음악은 행성·보스별 합성 음색 구성입니다. 전용 녹음 사운드트랙·오디오 자산 제작은 포함하지 않습니다.
- 자동 행성 화물망, 원격 건설·수리, ODYSSEY·ARK는 후속 단계입니다.
- OMEGA는 기록과 좌표만 존재합니다. 실제 착륙·최종 보스·다른 항성계·테라포밍·온라인 협동은 구현하지 않았습니다.
- Phase 7 직업·스킬 시스템은 기존 무기/스킬 ID와 공유 EquipmentSystem·전투 페이로드를 확장할 수 있습니다. 이번 단계에서는 직업을 임의로 추가하지 않았습니다.
